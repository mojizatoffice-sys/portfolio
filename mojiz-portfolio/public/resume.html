MindVault — Offline AI Knowledge Base

Python · RAG

Chat with your own PDFs; nothing leaves the machine.

  • FastAPI backend: /upload and /chat, with a file-type allowlist for PDF, TXT and Markdown.
  • Chunks text at 800 chars with 150 overlap, embeds via nomic-embed-text through Ollama, stores in a persistent ChromaDB collection using cosine distance.

  • Fully local inference with Llama 3.2 — no API keys, no cloud calls.
